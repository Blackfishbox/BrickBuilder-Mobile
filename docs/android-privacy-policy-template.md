## Local operation

This Android version builds and edits brick models locally. Projects, autosave
data, imported files, inventory lists and installed part data are processed in
application-local storage. We do not operate an account system, advertising,
analytics or model-upload service in this Android build.

The app does not request Internet permission. Its offline catalog and included
part/connection data ship with the application. The publisher does not receive
your project files through this build.

## Files you choose to import or share

When you select a file with Android's file chooser, the application reads that
file to import a project or inventory. Export creates a local temporary file and
opens Android's sharing/saving sheet. Only a destination you choose receives the
export. An external file provider or share target may operate its own cloud
service and privacy policy. Importing a file does not authorize uploading it.

## Retention and deletion

Projects remain in the application's local storage until you delete them,
clear app data or uninstall. Local export files can temporarily remain in
Android's app cache. System/app cache cleanup may remove them. Manually saved
exports remain at the destination you selected until removed there.

System cloud backup is disabled in the application's manifest. Always keep
your own verified exports; uninstalling or clearing app data can delete
application-local projects permanently.

## Permissions and external services

No location, camera, contacts, microphone, account, broad-storage or advertising
permissions are required by the prepared build. System document/share dialogs
use Android's scoped file access. Following an external attribution/license
link may open your web browser, whose network and privacy settings apply.

Google Play and Android/System WebView can independently process information
under Google's or the device vendor's policies. This policy describes the app,
not those separately operated platform services.

## Changes and questions

Update this policy if the application adds networking, telemetry, accounts,
