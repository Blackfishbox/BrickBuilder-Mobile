# BrickBuilder application icon

The transparent PNGs depict unbranded interlocking construction bricks in sage
green and terracotta. They are original generated artwork, not copied brand
logos. This is not a trademark clearance or an assertion of affiliation.

- `brickbuilder-512.png`: 512 × 512 RGBA source for application identity.
- `brickbuilder-192.png`: smaller PWA and browser icon.

Keep transparency in the application header and exported source image. Android
launcher variants live on the Android branch; their adaptive foreground must
retain safe-area padding for launcher masks. A launcher can still supply its
own background or icon treatment.
